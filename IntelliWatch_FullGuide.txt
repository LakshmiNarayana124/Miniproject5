█  SECTION 7 — FIX "NOT SECURE" WHEN IP CHANGES                 █
████████████████████████████████████████████████████████████████████

  When your Wi-Fi IP changes, the cert no longer matches.

  Step 1 — Find new IP:
    ipconfig | findstr "IPv4"
    (e.g., 192.168.1.15)

  Step 2 — Regenerate cert (run in project root):
    cd C:\Users\Dell\Downloads\IntelliWatch_PC_Ready
    python -c "
    import datetime, ipaddress
    from cryptography import x509
    from cryptography.x509.oid import NameOID
    from cryptography.hazmat.primitives import hashes, serialization
    from cryptography.hazmat.primitives.asymmetric import rsa
    from cryptography.hazmat.backends import default_backend
    NEW_IP = '192.168.1.15'  # CHANGE THIS to your new IP
    key = rsa.generate_private_key(65537, 2048, default_backend())
    subj = x509.Name([x509.NameAttribute(NameOID.COMMON_NAME, 'IntelliWatch LAN')])
    cert = (x509.CertificateBuilder().subject_name(subj).issuer_name(subj)
        .public_key(key.public_key()).serial_number(x509.random_serial_number())
        .not_valid_before(datetime.datetime.now(datetime.timezone.utc))
        .not_valid_after(datetime.datetime.now(datetime.timezone.utc)+datetime.timedelta(days=825))
        .add_extension(x509.SubjectAlternativeName([
            x509.DNSName('localhost'),
            x509.IPAddress(ipaddress.IPv4Address('127.0.0.1')),
            x509.IPAddress(ipaddress.IPv4Address(NEW_IP))]),False)
        .add_extension(x509.BasicConstraints(ca=True,path_length=None),True)
        .sign(key,hashes.SHA256(),default_backend()))
    open('certs/intelliwatch-wifi.crt','wb').write(cert.public_bytes(serialization.Encoding.PEM))
    open('certs/intelliwatch-wifi.key','wb').write(key.private_bytes(serialization.Encoding.PEM,serialization.PrivateFormat.TraditionalOpenSSL,serialization.NoEncryption()))
    print('Cert regenerated for', NEW_IP)
    "

  Step 3 — Install new cert:
    certutil -user -addstore Root "certs\intelliwatch-wifi.crt"

  Step 4 — Restart frontend:
    Ctrl+C in frontend terminal, then:  npm run dev

  Step 5 — Update Firebase authorized domains:
    Firebase Console → Authentication → Settings → Authorized domains
    Add your new IP.

█  SECTION 11 — TROUBLESHOOTING                                   █
████████████████████████████████████████████████████████████████████

  ┌─────────────────────────────────────────────────────────────┐
  │ Problem: Backend won't start                                │
  └─────────────────────────────────────────────────────────────┘
    Check:
      echo %INTELLIWATCH_SECRET_KEY%
    If empty:
      set INTELLIWATCH_SECRET_KEY=<generate with:>
      python -c "import secrets; print(secrets.token_hex(32))"
    Then restart backend.

    Check port not in use:
      netstat -ano | findstr :8000
    If occupied, kill the process or use different port:
      python -m uvicorn server:app --host 0.0.0.0 --port 8001


  ┌─────────────────────────────────────────────────────────────┐
  │ Problem: Frontend won't start                                │
  └─────────────────────────────────────────────────────────────┘
    Check Node installed:
      node --version
    If not 18+, update Node.js.
    Reinstall deps:
      cd frontend
      rm -rf node_modules
      npm install
      npm run dev

    Check port not in use:
      netstat -ano | findstr :5173


  ┌─────────────────────────────────────────────────────────────┐
  │ Problem: "Not Secure" on network                             │
  └─────────────────────────────────────────────────────────────┘
    Install cert (see Section 1.4).
    If IP changed, regenerate cert (see Section 7).
    On mobile: click "Advanced → Proceed anyway" (safe for dev).


  ┌─────────────────────────────────────────────────────────────┐
  │ Problem: Google Sign-In shows error                         │
  └─────────────────────────────────────────────────────────────┘
    "auth/configuration-not-found":
      → Firebase Console → Authentication → Enable Google
    "auth/unauthorized-domain":
      → Firebase Console → Authorized domains → Add your domain/IP
    "Firebase authentication is not available on this server":
      → Backend .env missing FIREBASE_PROJECT_ID
      → Or backend not restarted after .env change


  ┌─────────────────────────────────────────────────────────────┐
  │ Problem: Phone OTP shows error                               │
  └─────────────────────────────────────────────────────────────┘
    "auth/billing-not-enabled":
      → Firebase Spark plan doesn't support Phone Auth
      → Upgrade to Blaze plan (pay-as-you-go, 10 free SMS/month)
    "auth/invalid-phone-number":
      → Check country code + number format
    "auth/captcha-check-failed":
      → Refresh page, try again (reCAPTCHA reset)


  ┌─────────────────────────────────────────────────────────────┐
  │ Problem: Profile page not showing after login               │
  └─────────────────────────────────────────────────────────────┘
    Hard refresh:  Ctrl + Shift + R
    If still not showing:
      → Check Navbar has 👤 Profile link
      → Go directly to https://localhost:5173/profile


  ┌─────────────────────────────────────────────────────────────┐
  │ Problem: Page blank after login                             │
  └─────────────────────────────────────────────────────────────┘
    Check browser console (F12) for errors.
    Most common: sessionStorage blocked → enable cookies/storage.
    Try: hard refresh (Ctrl+Shift+R).


  ┌─────────────────────────────────────────────────────────────┐
  │ Problem: CORS error in browser console                       │
  └─────────────────────────────────────────────────────────────┘
    Backend CORS doesn't include your origin.
    Edit Backend/.env:
      INTELLIWATCH_CORS_ORIGINS=https://192.168.1.8:5173,https://localhost:5173
    Restart backend.
